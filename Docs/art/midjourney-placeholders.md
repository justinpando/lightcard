# Midjourney Placeholder Prompts — v2 Catalog (34 cards)

## Workflow

1. Generate with the prompts below (square, `--ar 1:1`).
2. Save each image as `Assets/Art/CardPlaceholders/<exact card name>.png`
   (e.g. `Assets/Art/CardPlaceholders/Siege Knight.png`), overwriting the
   procedural placeholder if one exists.
3. Run **LightCard → Sync Card Assets From Catalog**. A PNG in that folder
   always wins: it replaces procedural art *and* the old 2021 sketches, and the
   deck builder, hand, and board tokens all update automatically.

## House style

Append to every prompt for a consistent set:

> `loose ink and watercolor illustration, symbolic dreamlike imagery from the
> collective unconscious, minimal background, soft vignette, card game art
> --ar 1:1 --no text, letters, frame, border`

Archetype palettes (from the design sheet): **Garden** verdant greens with rose
accents · **Expedition** warm golds and sunlit ochre · **Atelier** deep
workshop blues with brass · (later: Heart embers-red, Ocean violet, Tower
iron-black).
